# The Internet in One Word

Entry for the [make.fun bounty "The Internet in One Word"](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b) — one word for the whole internet, funniest and most fitting wins.

## The word

**unhinged**

One word, no explanation needed: the whole internet, every corner of it, at once, all the time. A reader laughs, then nods.

## How it works

`main.ts` writes the word to `/output/entry.txt` (UTF-8, 8 characters, within the 1–30 character gate) and self-checks the gate before writing.

```sh
node main.ts
cat /output/entry.txt
# unhinged
```
